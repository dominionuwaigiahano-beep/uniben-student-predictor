About this system

A decision-support tool that predicts undergraduate academic risk so that advisors can intervene early, before a student's performance deteriorates beyond recovery.

How it works

The system was built by training five supervised machine learning classifiers — Decision Tree, Random Forest, Logistic Regression, Support Vector Machine and K-Nearest Neighbour — on student academic and background data. Each model was evaluated using ten-fold cross-validation and standard metrics: accuracy, precision, recall, F1-score and AUC-ROC.

The {{ model_name }} model performed best overall and powers the live predictions on the assessment page. Class imbalance in the training data was addressed with SMOTE, and the most informative predictors were identified using Recursive Feature Elimination.

Predictions are estimates intended to guide human judgement. They do not replace the assessment of academic staff and are not final determinations of a student's results.
